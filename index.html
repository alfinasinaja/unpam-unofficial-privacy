Kebijakan Privasi UNPAM Unofficial

Terakhir diperbarui: 7 November 2026

UNPAM Unofficial adalah aplikasi tidak resmi yang dikembangkan secara mandiri. Aplikasi ini bukan produk resmi Universitas Pamulang dan tidak berafiliasi dengan pihak kampus.

1. Siapa yang mengembangkan aplikasi ini

Aplikasi ini dikembangkan oleh Alfinas Sandi, mahasiswa Teknik Informatika Universitas Pamulang. Pertanyaan tentang privasi dapat dikirim ke alfinassandi@gmail.com.

2. Data yang diproses

  • Kredensial login (NIM dan kata sandi) yang Anda masukkan, dipakai untuk masuk ke layanan resmi unpam.ac.id.
  • Token sesi yang disimpan di perangkat Anda. Token berlaku sekitar 1 minggu, setelah itu Anda perlu login ulang.
  • Data akademik seperti profil, jadwal, kartu ujian, tagihan, dan informasi lain yang ditampilkan di aplikasi. Data ini diambil langsung dari unpam.ac.id setiap kali Anda membukanya.
  • Foto mahasiswa yang diambil dari unpam.ac.id dan ditampilkan di aplikasi.
  • Akses notifikasi (opsional). Jika Anda mengaktifkannya, aplikasi hanya memproses notifikasi dari Telegram saat halaman verifikasi OTP sedang terbuka, untuk mengisi kode OTP secara otomatis. Isi notifikasi tidak disimpan dan tidak dikirim ke server mana pun. Notifikasi dari aplikasi lain diabaikan.

3. Data yang tidak dikumpulkan pengembang

Pengembang tidak memiliki server untuk menyimpan data pengguna. Data akademik dan akun Anda hanya berpindah antara perangkat Anda dan layanan resmi unpam.ac.id.

Donasi, jika Anda memilihnya, dilakukan langsung lewat aplikasi pembayaran Anda sendiri (QRIS). Aplikasi tidak menerima data pembayaran. Tombol konfirmasi hanya membuka WhatsApp atas inisiatif Anda.

4. Cara data digunakan

Data hanya digunakan untuk menampilkan informasi akademik Anda di aplikasi, memproses login, dan mengisi kode OTP jika fitur tersebut Anda aktifkan. Data tidak digunakan untuk iklan atau pelacakan.

5. Pembagian data

Pengembang tidak menjual, menyewakan, atau membagikan data pengguna kepada pihak ketiga. Satu-satunya pihak yang menerima data adalah layanan resmi UNPAM (unpam.ac.id), karena aplikasi mengambil data dari sana atas nama Anda.

Tautan ke WhatsApp dan Google Play hanya dibuka ketika Anda menekannya, dan kebijakan privasi layanan tersebut berlaku di sana.

6. Penyimpanan dan keamanan

Token dan kredensial login disimpan di perangkat Anda. Fungsi logout menghapus token tersebut dari perangkat. Menghapus data aplikasi dari pengaturan Android juga akan menghapus data yang tersimpan di perangkat.

7. Izin yang digunakan

  • Internet: untuk mengambil data dari unpam.ac.id.
  • Akses notifikasi (opsional): hanya untuk fitur OTP otomatis. Anda dapat mencabutnya kapan saja di Pengaturan > Akses Notifikasi.

8. Anak-anak

Aplikasi ini ditujukan untuk mahasiswa Universitas Pamulang dan tidak ditujukan untuk anak di bawah 13 tahun.

9. Hak Anda

  • Menghentikan penggunaan aplikasi dan menghapus data dari perangkat kapan saja.
  • Mencabut izin akses notifikasi dari pengaturan Android.
  • Untuk data akademik dan akun, hubungi pihak Universitas Pamulang.

10. Perubahan kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan akan ditampilkan di halaman ini dengan tanggal pembaruan yang baru.
